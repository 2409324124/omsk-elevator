# 鄂木斯克自适应开放视觉小说 Demo 文档包

本文件夹用于指导本地 agent 开发一个 20-30 分钟的封闭场景视觉小说 Demo。

项目暂名：

> 《电梯向下》

核心目标：

> 用“心理量表结构 + 自适应叙事路由 + 渐进式披露”制作一个过程高度开放、结局方向有限收束的视觉小说。

## 一句话定位

这不是传统分支树视觉小说。

它的设计目标是：

> 玩家以为自己在选择剧情，实际上是在改变剧情选择自己的概率。

## 重要边界

1. 不要把玩家心理状态说成临床诊断。
2. 不要直接复制现实心理量表原题。
3. 不要让玩家角色开天眼。
4. 不要让反直觉选择变成恶意剧情杀。
5. 不要让 LLM 直接决定结局。
6. 数值系统负责因果，LLM 只负责叙事表达。
