# 意识形态/政治价值观参考源

本项目新增 8values 作为政治价值观参考源，但它不是游戏内的现实政治倾向测评。它只提供轴和权重结构的参考，用于后续把“意识形态维度”转译成鄂木斯克封闭建筑场景里的价值冲突。

## 8values

- 参考源名称：8values
- 来源仓库：<https://github.com/8values/8values.github.io>
- 本轮允许使用的文件：
  - `README.md`
  - `LICENSE`
  - `questions.js`
- 本地参考文件：
  - `data/reference/8values/SOURCE.md`
  - `data/reference/8values/questions_raw.js`
  - `data/reference/8values/LICENSE`
  - `data/reference/8values/construct_mapping_draft.json`
- 许可证摘要：
  - 8values 仓库标识为 MIT License。
  - 本项目保留 `LICENSE` 的本地参考副本。

## 本项目如何使用

- 只借用四个轴和题项权重结构：
  - `econ`：economic equality vs markets
  - `dipl`：nation/sovereignty vs world/internationalism
  - `govt`：authority/security vs liberty
  - `scty`：tradition vs progress
- 不直接复制 `questions.js` 中的题目为游戏文本。
- 不把题目翻译成中文 scene。
- 后续只能把这些轴转译为鄂木斯克封闭建筑场景中的具体压力测试，例如安检、监听、胶卷扣押、统一口径、配给、避难床位、儿童训练和外宾管理。

## 禁止用途

- 不得输出“玩家是什么现实政治意识形态”。
- 不得把玩家路线归类为现实政治标签。
- 不得做现实政治画像、测评或劝导。
- 不得新增临床、极端主义或授权不明来源。
- 不得使用 Political Compass 或其他授权不明题库。

## 游戏内反馈规则

游戏内只能输出叙事反馈，例如：

> 你的路线显示：在极端压力下，你更愿意用秩序换取安全。

类似反馈必须描述玩家在剧情压力下的取舍，而不是现实政治身份、政党倾向或意识形态标签。
